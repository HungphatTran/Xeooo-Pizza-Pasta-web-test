# Xéooo Pizza & Pasta – Hệ Thống Đặt Bàn & Quản Lý Nhà Hàng

Dự án phát triển web app quản lý bàn tiệc, đặt bàn trực tuyến, sơ đồ mặt bằng thực tế 3 tầng, tính toán doanh thu và phân quyền nhân viên cho **Xéooo Pizza & Pasta (Cơ sở Đội Cấn)**.

## Hướng dẫn cài đặt và chạy trên máy tính

1. Cài đặt **Node.js** (tải tại https://nodejs.org/ phiên bản LTS).
2. Mở terminal tại thư mục dự án và chạy:
   ```bash
   npm install
   ```
3. Khởi chạy ứng dụng:
   ```bash
   npm run dev
   ```
4. Truy cập web tại: `http://localhost:3000` (hoặc cổng hiển thị trong terminal).
